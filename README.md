# Igggy Releases

Public release channel for **Igggy Mac** — notarized DMGs (as GitHub Release assets) and the Sparkle `appcast.xml` update feed.

- The app checks `https://igggy.ai/releases/appcast.xml`, which redirects here.
- No source code lives here — only release artifacts.

Releases are cut with `scripts/release.sh` in the private `igggy-mac` repo. See its `docs/RELEASING.md`.
